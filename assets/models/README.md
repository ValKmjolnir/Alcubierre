# Models

- `kenney_space_kit/` — the eight spacecraft from Kenney's Space Kit, CC0 1.0.
  License and provenance: `kenney_space_kit/LICENSE.txt`.
- `ship_py.glb` — the escort corvette used by the scene. Generated from
  `tool/build_ship.py` (run it with Blender), so it carries no third-party
  license; it is built to the project's own blockout spec.
